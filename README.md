# দেশখোঁজ (DeshKhoj)

বাংলাদেশের প্রতিটি পথ, আপনার হাতের মুঠোয়।

দেশখোঁজ একটি সহজ ও ব্যবহারবান্ধব অ্যাপ।

## প্রধান সুবিধা

- বাংলাদেশের বিভাগসমূহ
- জেলার তালিকা
- উপজেলার তথ্য
- দর্শনীয় স্থান
- স্থানভিত্তিক তথ্য অনুসন্ধান

## আমাদের লক্ষ্য

বাংলাদেশের বিভিন্ন স্থানের তথ্য সহজে মানুষের কাছে পৌঁছে দেওয়া।
